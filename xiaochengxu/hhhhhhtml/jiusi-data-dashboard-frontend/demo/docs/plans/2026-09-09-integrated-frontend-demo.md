# 逆水寒联赛综合纯前端 Demo 实施计划

## 目标

依据《逆水寒联赛组织与数据分析综合项目文档》，把现有数据分析小程序扩展为覆盖登录、活动、组织、报名、活动管理、赛后分析和个人中心的纯前端微信小程序 Demo。所有新业务数据使用本地假数据，不接入后端。

## 视觉方向

- 主题：夜战指挥台。
- 背景：深墨蓝和低对比纹理。
- 活动操作：赤金色强调。
- 数据分析：青绿色与冰蓝色强调。
- 卡片：克制的深色分层、细边框和角标，不使用通用白底紫色模板。

## 任务

### 任务 1：假数据状态层

- 新增综合业务假数据。
- 新增本地状态仓库。
- 支持登录、资料保存、活动筛选、报名、撤离、发布活动和加入组织。
- 先编写 Node.js 纯函数测试，再实现状态层。

### 任务 2：应用入口和全局视觉

- 将登录页设为启动页面。
- 将底部导航调整为“活动、组织、分析、我的”。
- 加载原分析状态与新 Demo 状态。
- 建立统一的全局色彩、按钮、卡片、状态标签和动效。

### 任务 3：登录、活动和活动详情

- 实现登录/注册演示页面。
- 实现帮会、俱乐部、公开活动切换。
- 实现活动卡片、报名进度和管理入口。
- 实现 60/120 人椅子矩阵、本人/代理报名、详情和撤离交互。

### 任务 4：组织、活动管理和个人中心

- 实现组织概览、成员、权限、邀请码和团队编排预览。
- 实现活动发布表单、历史活动和 CSV 演示操作。
- 实现个人资料编辑、组织入口、重置 Demo 和退出登录。

### 任务 5：接入现有分析模块

- 在总览、玩家、队伍和盒子页面加入统一分析二级导航。
- 展示当前分析活动上下文。
- 修正原来依赖底部 TabBar 的页面跳转。
- 保留 JSON/CSV 导入、玩家详情和盒子编辑能力。

### 任务 6：验证和收尾

- 运行全部 Node.js 测试。
- 检查所有 JavaScript 语法。
- 检查页面配置、事件绑定和目标文件。
- 在微信开发者工具中进行界面检查（条件允许时）。

## 验收标准

- 启动后能够进入登录页并登录到活动首页。
- 底部显示活动、组织、分析、我的四个入口。
- 活动页能够切换分类并进入活动详情。
- 空椅子可以进行本人或代理报名，已占椅子可以查看和撤离。
- 活动管理可以创建假活动并演示 CSV 状态。
- 组织页能展示成员、角色、邀请码和团队编排。
- 分析页能进入总览、玩家、队伍和盒子。
- 盒子原有导入、队伍/玩家编辑和指标功能保持可用。
- 所有数据均在前端本地运行，不发起后端请求。
