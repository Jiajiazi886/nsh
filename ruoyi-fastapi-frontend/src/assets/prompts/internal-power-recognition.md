# 逆水寒手游内功右侧属性识别 Skill（最终精简版）

## 1. 目标

识别《逆水寒手游》内功截图中，**屏幕右侧当前选中的内功信息**。

只识别并输出：

1. 内功名
2. 元素
3. 属性加成

不输出：

- 等级
- 评分
- 标签
- 进攻能力
- 左侧内功列表
- 筛选状态
- 底部按钮
- 总修为
- 内功修为
- 其他界面信息

---

## 2. 固定输出格式

默认只输出 JSON，结构固定如下：

```json
{
  "内功名": "",
  "元素": "",
  "属性加成": [
    {
      "词条": "",
      "数值": ""
    }
  ]
}
```

---

## 3. 识别范围

只看截图右侧当前选中的内功面板。

不要识别左侧背包中的其他内功。
不要统计内功数量。
不要输出截图中能看到但不需要的字段。

---

校正规则：

- 稀有内功截图中只显示本名时，也要输出白名单名。
  - `日月两仪` 输出 `稀有-日月两仪`
  - `不动明王` 输出 `稀有-不动明王`

  - `灼星贯日` 输出 `稀有-灼星贯日`
- 名称中的 `·试用` 不输出。
  - `绝电惊沙·试用` 输出 `稀有-绝电惊沙`

## 5. 元素识别规则

元素只能输出：

```json
["金", "木", "水", "火", "土", "金木水火土"]
```

基础判断：

| 元素       | 图标/颜色特征                        |
| ---------- | ------------------------------------ |
| 金         | 黄色三角图标，金黄色光效             |
| 木         | 绿色叶子图标，绿色/青绿色光效        |
| 水         | 蓝色水滴图标，蓝色/冰蓝色光效        |
| 火         | 红色火焰图标，红橙色光效             |
| 土         | 土黄色山形/三角图标，土黄/金棕色光效 |
| 金木水火土 | 五韵谣专用                           |

稀有内功存在同名不同元素，需要根据图标颜色判断元素。

| 稀有-日月两仪 | 火   | 红橙色、赤金色、日轮感、火焰感    |
| 稀有-日月两仪 | 土   | 土黄色、金棕色、古铜色、罗盘感    |
| 稀有-不动明王 | 木   | 青绿色、翡翠绿、绿色玉石质感      |
| 稀有-不动明王 | 水   | 冰蓝色、浅蓝色、蓝白冰晶质感      |
| 稀有-绝电惊沙 | 木   | 亮绿色、青绿色、绿色羽刃/叶片闪电 |
| 稀有-绝电惊沙 | 金   | 金黄色、浅金色、金色羽刃/闪电     |
| 稀有-承影锋烁 | 金   | 金黄色、亮金色、金色扇形剑影      |
| 稀有-承影锋烁 | 火   | 红橙色、赤金色、火焰外圈剑影      |
| 稀有-灼星贯日 | 木   | 亮绿色、黄绿色、绿色燃烧星核/陨石 |
| 稀有-灼星贯日 | 火   | 红橙色、橙黄色、红橙燃烧星核/陨石 |

## 7. 属性词条白名单

属性加成中的词条只能从以下列表中匹配：

```json
[
  "攻击",
  "力量/气海",
  "赛年伤害/治疗提高",
  "最小攻击",
  "最大攻击",
  "流派克制",
  "破防",
  "会心",
  "耐力",
  "根骨",
  "身法",
  "内功防御",
  "首领抵御",
  "流派抵御",
  "抗会心",
  "防御",
  "气血上限",
  "首领克制",
  "抗内功会心",
  "抗外功会心",
  "外功防御",
  "灵韵"
]
```

常见校正：

| 识别结果            | 正确输出   |
| ------------------- | ---------- |
| 流派抵制            | 流派抵御   |
| 抗外攻会心          | 抗外功会心 |
| 抗内攻会心          | 抗内功会心 |
| 气血上很 / 气血上狠 | 气血上限   |
| 首领抵抗            | 首领抵御   |
| 内功防御力          | 内功防御   |
| 外功防御力          | 外功防御   |
| 灵韵特性效果等级    | 灵韵       |

---

## 8. 数值规则

- `+2084` 输出为 `2084`
- `+0.9%` 输出为 `"0.9%"`
- 百分比必须保留 `%`，并用字符串输出
- 普通整数输出为数字
- 重复词条不要合并
- 属性按截图从上到下输出
