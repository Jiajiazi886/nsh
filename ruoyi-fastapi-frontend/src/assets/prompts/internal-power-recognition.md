# 逆水寒手游内功右侧属性识别 Skill

## 1. Skill 目标

本 Skill 用于识别《逆水寒手游》内功界面截图中，**屏幕右侧当前选中的内功名与属性加成**。

只识别两个内容：

1. 内功名
2. 属性加成

不识别、不输出以下内容：

- 标签
- 等级
- 评分
- 进攻能力
- 元素
- 左侧内功背包列表
- 底部按钮
- 筛选状态
- 总修为/内功修为
- 其他界面信息

---

## 2. 输出字段

默认只输出 JSON，结构固定如下：

```json
{
  "内功名": "",
  "属性加成": [
    {
      "词条": "",
      "数值": ""
    }
  ]
}
```

---

## 3. 核心识别原则

1. **只识别右侧当前选中的内功**
   - 不识别左侧背包里的其他内功。
   - 不统计内功数量。
   - 不输出界面按钮、筛选项、评分、等级、标签、进攻能力等内容。

2. **只输出内功名和属性加成**
   - 即使截图中能看到等级、评分、标签、进攻能力，也不要输出。
   - 即使能看出元素，也不要输出元素。

3. **内功名必须从白名单中匹配**
   - 如果视觉识别/OCR 得到的内功名不在白名单里，需要进行相近字校正。
   - 例如：`黄山月` 应校正为 `贯山月`。

4. **属性词条必须从白名单中匹配**
   - 如果识别出错字、近似字、漏字，需要校正到合法词条。
   - 不允许输出白名单外的属性词条。

5. **属性加成按截图从上到下输出**
   - 不要改变顺序。
   - 重复词条不要合并。
   - 同名词条出现多次，就输出多次。

6. **数值保持原始含义**
   - 普通数值输出为数字。
   - 百分比数值保留 `%`。
   - 正负号按截图含义处理。
   - `+2084` 可以输出为 `2084`。
   - `+0.9%` 输出为 `"0.9%"`。

## 7. 属性词条校正规则

当截图识别结果与白名单不完全一致时，应优先校正到白名单词条。

| 可能识别结果 | 正确输出 |
|---|---|
| 流派抵制 | 流派抵御 |
| 抗外攻会心 | 抗外功会心 |
| 抗内攻会心 | 抗内功会心 |
| 气血上很 | 气血上限 |
| 气血上狠 | 气血上限 |
| 首领抵抗 | 首领抵御 |
| 首领克制值 | 首领克制 |
| 内功防御力 | 内功防御 |
| 外功防御力 | 外功防御 |
| 灵韵特性效果等级 | 灵韵 |

如果无法确定词条，应输出最接近的白名单词条，并避免创造新词条。

## 8. 数值格式规范

### 8.1 普通整数

截图显示：

```text
气血上限 +2084
```

输出：

```json
{
  "词条": "气血上限",
  "数值": 2084
}
```

### 8.2 百分比

截图显示：

```text
流派抵御 +0.9%
```

输出：

```json
{
  "词条": "流派抵御",
  "数值": "0.9%"
}
```

### 8.3 重复词条

截图显示多个同名词条时，不合并：

```json
[
  {
    "词条": "气血上限",
    "数值": 2084
  },
  {
    "词条": "气血上限",
    "数值": 782
  },
  {
    "词条": "气血上限",
    "数值": 921
  }
]
```

## 10. 禁止事项

识别结果中禁止输出以下字段：

```json
[
  "元素",
  "等级",
  "评分",
  "标签",
  "进攻能力_哨塔",
  "总修为",
  "内功修为",
  "左侧内功列表",
  "筛选状态"
]
```

禁止行为：

1. 不要识别左侧内功背包列表。
2. 不要统计所有内功数量。
3. 不要输出白名单外的内功名。
4. 不要输出白名单外的属性词条。
5. 不要把重复词条合并。
6. 不要把百分比转成小数。
7. 不要自行推测截图中没有显示的隐藏属性。
8. 不要把“灵韵特性效果等级”完整输出，应统一输出为“灵韵”。
9. 不要输出等级、评分、标签、进攻能力。
10. 不要输出元素字段。

---

## 11. 最终执行提示词

当用户上传《逆水寒手游》内功截图并要求识别时，按以下方式执行：

```text
只识别截图右侧当前选中的内功。
只输出“内功名”和“属性加成”两个字段。
不要输出标签、等级、评分、进攻能力、元素。
内功名必须从内功名白名单中匹配。
属性词条必须从属性词条白名单中匹配。
如果识别结果有错字或近似字，自动校正到白名单。
属性按截图从上到下输出。
重复词条不要合并。
百分比保留为字符串。
默认只输出 JSON，不解释。
```
