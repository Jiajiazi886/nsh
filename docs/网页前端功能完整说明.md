## 1. 文档目的

本文介绍网页前端的定位、菜单、页面、按钮、权限和数据来源，重点说明“帮会管理”和“个人管理”。

本文以当前代码为准，统一使用以下业务规则：

- 网页与小程序使用同一后端、同一账号和同一数据库。
- “我的约战”只负责查看，不允许创建约战。
- 新约战只能在“帮会管理 → 分团管理 → 约战排表”创建。
- 管理员或助手点击保存后，网页和小程序才读取到新的阵容快照。
- 旧的未关联战报已经清理，战报必须明确归属活动。
- 网络失败时显示真实错误，不使用假数据冒充后端结果。

## 2. 网页前端定位

网页端是整个系统的管理端和复杂操作端，适合电脑使用，主要承担：

- 后台账号、角色、菜单和系统配置管理。
- 帮会资料、成员、审核、职业和颜色管理。
- 创建约战并使用大屏幕拖拽方式配置阵容。
- 保存活动阵容快照、公开活动、结束活动和导入战报。
- 查看本人活动、公开活动、历史战报和详细阵容。
- 维护个人玩家资料、内功和计算器数据。

前端技术主体为 Vue 3、Vue Router、Pinia、Element Plus 和 Vite。开发服务默认地址为 `http://127.0.0.1:5173`，请求通过 `/dev-api` 代理到 FastAPI 后端。

## 4. 登录与注册界面

### 4.1 登录页

界面功能：

- 输入账号和密码。
- 根据后端配置决定是否显示验证码。
- 登录成功后保存 JWT，并读取当前账号、角色和菜单权限。
- 登录失败显示后端返回的真实原因。
- 支持进入注册页。

账号规则：

- 与微信小程序使用同一个后端账号。
- 玩家 UID、玩家名字、微信号都不是登录账号。
- 微信一键登录和微信授权绑定当前尚未接入。

### 4.2 注册页

界面功能：

- 输入账号、密码、确认密码和验证码。
- 注册是否开放由后端开关决定。
- 注册成功后返回登录页。

注册只创建登录账号，不自动加入帮会、不自动创建成员、不自动获得管理权限。

## 5. 帮会管理

### 5.1 帮会信息

用途：查看和维护当前帮会的基础资料。

页面通常展示或维护：

- 帮会名称和标识。
- 帮会当前状态。
- 帮会负责人和基础说明。
- 当前账号在帮会中的身份。

权限原则：

- 普通成员以查看为主。
- 管理员或拥有对应权限的账号可以修改。
- 后端会再次校验帮会归属，不能仅依靠前端按钮隐藏。

### 5.2 成员管理

用途：维护已经审核通过且仍然有效的帮会成员名册。

列表字段：

- 玩家名。
- 主职业和副职。
- 成员来源。
- 帮会身份。
- 请假次数。
- 备注。

页面功能：

- 按职业筛选成员。
- 显示全部成员。
- 手动添加帮会成员。
- 导入成员 JSON。
- 从历史战斗数据选择帮会并导入成员。
- 编辑玩家名、主职业、副职和备注。
- 单个删除或批量删除成员。
- 查看已经绑定账号的成员玩家资料。

成员私人资料弹窗可显示：

- 名字。
- 玩家 UID。
- 微信号。
- 是否拥有橙武。

隐私规则：微信号仅本人以及该帮会真实管理员／助手可见。未绑定账号的成员不会伪造账号玩家资料。

### 5.3 分团管理与约战排表

“分团管理”当前是菜单目录，主要业务页面是“约战排表”。旧式独立分团表格不再作为主要配置方式。

#### 5.3.1 排表入口页

页面功能：

- 创建新约战。
- 选择本人可以管理且尚未结束的已有约战。
- 进入所选活动的阵容配置。
- 跳转到“我的约战”查看已保存结果。

创建约战只能在这里进行。创建表单包含：

- 所属组织：本人有管理权限的帮会或俱乐部。
- 活动名称。
- 约战时间。
- 活动说明。

约战时间只有一个业务字段。默认选择最近一个尚未错过的周二或周四 20:30，也可以手动修改。

#### 5.3.2 阵容编辑页

页面层级：

```text
活动
└─ 团队
   └─ 小队
      ├─ 位置 1
      ├─ 位置 2
      ├─ 位置 3
      ├─ 位置 4
      ├─ 位置 5
      └─ 位置 6
```

团队功能：

- 创建团队。
- 修改团队名称。
- 删除团队。
- 展开或收起团队。
- 团队本身不能直接放玩家。

小队功能：

- 在团队中创建小队。
- 修改小队名称。
- 删除小队。
- 小队固定包含六个位置。
- 小队采用竖向紧凑排列，电脑宽屏可让两个团队并排。

候选玩家区：

- 只读取当前活动所属组织允许安排的成员。
- 按职业树归类。
- 所有职业目录默认收起。
- 每个职业使用统一的职业颜色。
- 支持按玩家名或职业搜索。
- 显示玩家是否已经被安排。

玩家安排：

- 从候选区拖入空位。
- 从一个位置拖到另一个空位。
- 同队或跨队移动。
- 双方位置都有人时执行交换。
- 点击小型“移出”按钮将玩家移回候选区。
- 位置内不再提供“选择玩家”按钮或点击选人弹窗。
- 玩家变动只更新当前页面，不会整页刷新。

位置职业要求：

- 每个位置可设置“不限职业”或一个指定职业。
- 空位使用明显的浅黄色底和“空缺”文字。
- 指定职业使用对应职业颜色。
- 玩家职业不符合目标位置时拒绝拖入并提示原因。
- 交换时校验两端职业要求；任意一端不符合则整次交换取消。

临时替补：

- 管理员或助手可以创建当前活动的临时替补。
- 临时替补需要名字和职业。
- 可以像正式成员一样参与排表。
- 只在当前活动及其快照中有效。
- 不加入永久帮会成员表，也不会获得组织访问权限。

本地草稿和保存：

- 页面每 10 秒将草稿保存到浏览器 IndexedDB。
- 草稿按后端地址、账号和活动隔离。
- 自动保存不会更新其他用户或小程序看到的阵容。
- 点击“保存”才向后端提交并生成新快照。
- 保存使用活动修订号和防重复操作标识。
- 保存冲突时要求重新读取，不能静默覆盖他人修改。
- 后端保存失败时保留本地草稿，成员仍看到上一份成功快照。
- 支持查看多次保存形成的历史快照。

#### 5.3.3 活动状态操作

保存阵容、公开活动和结束活动是三个不同操作：

- 保存阵容：生成成员可见的新快照。
- 发布公开：活动进入“找约战”，组织外符合条件的用户可报名。
- 结束活动：停止编辑和报名，保留最终阵容并进入历史。

### 5.4 审核管理

#### 5.4.1 成员审核

页面功能：

- 查看待审核入会申请。
- 查看申请帮会、申请账号、玩家名、主职业、副职、备注和申请时间。
- 管理员或帮会负责人执行通过或拒绝。
- 普通帮会负责人只能处理本帮会申请。
- 已拒绝或仍待审核的数据不会进入正式成员列表。

#### 5.4.2 约战审核

此页面属于旧邀请链接／报名审核流程的兼容功能，与新版活动的公开空位直接报名不是同一个入口。

页面功能：

- 生成带有效期的公开报名链接。
- 查看邀请链接和报名数量。
- 复制或停用链接。
- 按待审核、已通过、已拒绝筛选。
- 按报名或请假类型筛选。
- 审核申请并查看玩家、职业、帮会身份、联系方式和备注。

后续开发应逐步明确该兼容流程是否并入新版活动系统，避免产生两种相似但数据不同的约战报名。

### 5.5 数据分析

用途：对已经导入并保存的历史战斗数据进行电脑端复盘。

页面功能：

- 选择历史战斗数据。
- 选择历史排表阵容。
- 按队伍、玩家、职业或帮会查看对象。
- A/B 两对象快速对比和交换。
- 多人对比。
- 全量指标数据墙。
- 柱状图、折线图、饼图。
- 同职业分析。
- 击败、人伤、治疗、承伤等关键榜单。
- 团队复盘和职业贡献。
- 显示排表中未匹配玩家和数据中未排表玩家，交给管理员人工确认。

数据分析不会根据标题或日期自动猜测活动关系。新版活动战报必须明确绑定活动 ID。

### 5.6 职业颜色设置

用途：统一整个网页和小程序的职业显示颜色。

页面功能：

- 查看所有职业的背景色和文字色。
- 修改职业颜色。
- 保存自定义配置。
- 未设置时使用明显的默认色。

颜色覆盖：候选树、阵容位置、活动缺口、成员列表、主副职业、玩家分析和战报等职业标签。

### 5.7 职业信息

用途：维护系统允许使用的职业字典。

页面功能：

- 搜索职业名称和状态。
- 查看职业编号、名称、显示顺序、状态、备注和创建时间。
- 按权限新增、编辑、启停或删除职业。
- 职业启停会影响排表和个人资料中的可选职业，但不会追改历史快照。

### 5.8 帮会管理中的约战信息

#### 我的约战

- 展示当前账号所属帮会和俱乐部的未结束活动。
- 电脑端左侧为帮会活动，右侧为俱乐部活动。
- 展示活动名称、组织、状态、约战时间、人数、职业缺口和战报状态。
- 点击进入共用活动详情。
- 此页面只允许查看，不提供创建约战。
- 拥有相应权限时仍可创建俱乐部；这是创建组织，不是创建约战。

#### 找约战

- 只展示已经明确发布公开且仍可查看的活动。
- 按职业缺口筛选。
- 仅查看有空位的活动。
- 显示组织、约战时间、已安排人数、总席位、空位和职业缺口。
- 点击进入详情并按资格报名。

#### 历史战报

- 查看所属组织的历史活动。
- 查看本人参加过且有权访问的公开活动历史。
- 没有战报时显示“暂无战报数据”。
- 只展示明确关联到活动的战报。

#### 约战详情

详情不是独立菜单，而是从活动列表进入。页面显示：

- 活动名称、组织、状态、时间和说明。
- 当前修订号和阵容快照版本。
- 团队、小队、六个位置、玩家和职业要求。
- 空缺位置和职业缺口。
- 本人报名、请假或离位入口。
- 管理员的配置排表、发布、结束和战报导入入口。
- 已关联战报的查看入口。

## 6. 个人管理

### 6.1 加入帮会

页面功能：

- 搜索可申请的帮会。
- 选择目标帮会。
- 填写玩家名、主职业、副职和备注。
- 提交入会申请。
- 查看当前申请状态和历史申请记录。
- 在允许的状态下撤回申请。

规则：

- 一个账号同一时间只能有一个有效申请，或已经加入一个帮会。
- 帮会负责人和平台管理角色不走普通成员申请流程。
- 审核通过后才进入正式成员列表。

### 6.2 内功管理

页面功能较多，主要包括：

- 新增、复制、编辑和删除个人内功。
- 搜索内功名，按种类或元素筛选。
- 批量选择、批量删除和清空。
- 配置内功名称、级别、元素、词条、数值、灵韵和备注。
- 图片识别生成草稿。
- 查看和清理识别历史。
- JSON 导入为草稿。
- 管理个人内功数量上限。
- 有权限时编辑内功基础数值目录。

图片识别结果只有确认导入并保存后才写入个人内功库。

### 6.3 个人中心

当前统一入口为 `/personal/profile-edit`。旧 `/user/profile` 会跳转到该页面，不再维护两个不同的个人中心。

资料字段：

- 名字：游戏玩家名，必填，最多 30 字。
- 玩家 UID：字符串保存，可保留前导零。
- 微信号：手填联系方式，不是微信绑定。
- 橙武：开关，默认关闭，当前不作为报名限制。
- 主职业。
- 副职。
- 备注：最多 500 字。

页面操作：

- 保存资料。
- 重置未保存修改。
- 重新从后端读取。
- 修改登录密码。

数据规则：

- 未加入帮会也可以维护个人资料。
- 一个登录账号只有一份玩家资料。
- 保存时同步本人有效绑定成员的公开字段，但不修改所属帮会和身份。
- 历史阵容、快照和战报不会因个人资料变更而被追改。
- 微信号仅本人和本帮会管理员／助手可见。

### 6.4 坦度计算器

页面功能：

- 选择职业和职业防御修正。
- 输入或识别防守方面板。
- 选择系统攻击面板或个人攻击面板。
- 计算 PVP 防御减免、会心率和伤害期望。
- 保存个人职业修正并恢复默认。
- 新增、编辑、删除个人攻击面板模板。
- 导入、导出和查看攻击面板示例 JSON。

### 6.5 拆塔计算器与素／鸿计算器

当前菜单已经保留，并复用计算器入口组件。具体独立公式和专属页面仍需后续继续完善，文档和界面不得把尚未实现的计算结果描述为已完成。

### 6.6 面板设置

页面功能：

- 选择面板模板。
- 恢复默认设置。
- 保存到坦度计算器。
- 上传图片识别面板数据。
- 查看识别结果和识别历史。
- 将识别结果设为攻击方或受击方。
- 选择个人攻击面板或系统参考面板。

### 6.7 个人管理中的约战信息

个人管理下同样包含“我的约战、找约战、历史战报”，与帮会管理入口完全共用数据和页面：

- 我的约战：查看本人所属组织活动，不能创建。
- 找约战：查找公开活动并报名。
- 历史战报：查看本人有权限访问的历史活动和战报。
- 详情页：查看阵容、报名、请假和战报。

## 7. 网页与小程序互通关系

| 网页操作 | 小程序结果 |
| --- | --- |
| 创建约战 | 小程序“活动”中可读取该组织活动 |
| 保存排表 | 小程序详情读取最新成功快照 |
| 修改位置职业 | 小程序空位显示相同职业要求和颜色 |
| 发布公开 | 小程序“公开活动”出现该活动 |
| 用户报名／请假 | 两端重新读取后看到同一位置结果 |
| 结束活动 | 两端历史活动中显示 |
| 导入并绑定 CSV 战报 | 小程序可读取该活动战报 |
| 修改个人资料 | 小程序个人中心读取相同资料 |
| 修改职业颜色 | 小程序职业标签读取相同颜色 |

## 8. 权限摘要

| 操作 | 普通成员 | 助手 | 管理员／所有者 | 组织外用户 |
| --- | --- | --- | --- | --- |
| 查看本组织活动 | 是 | 是 | 是 | 否 |
| 创建约战 | 否 | 是，限所属组织 | 是，限所属组织 | 否 |

## 9. 当前边界

- 当前微信机器人尚未接入。
- 微信一键登录和微信账号绑定尚未接入。
- 小程序不提供拖拽排表，复杂管理在网页完成。
- 活动保存成功不代表公开发布。
- 个人资料保存不代表加入帮会。
- 临时替补不属于永久成员。
- 本地草稿不属于后端共享数据。
- 旧未关联战报已经清理，后续不得恢复按名称或日期猜配逻辑。

## 10. 验收重点

- “我的约战”没有创建按钮。
- “约战排表”是唯一网页创建入口。
- 普通成员不能进入可编辑状态。
- 保存失败不覆盖上一份快照。
- 网页保存后小程序读取同一活动和版本。
- 职业颜色在所有页面一致。
- 微信号权限由后端校验。
- 空账号不显示假活动、假战报或假分析数据。
