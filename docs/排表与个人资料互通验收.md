## 接口契约与安全

所有接口使用同一后端认证账号，不从客户端接受资料归属账号 ID。

| 接口 | 权限与返回 |
| --- | --- |
| `GET /api/v1/profession-styles` | 普通登录用户也可读取本人显示配置；`profession、backgroundColor、textColor` |
| `GET /api/v1/player-profile/me` | 仅本人；未保存时读取最新有效绑定成员预填，不自动写库 |
| `PUT /api/v1/player-profile/me` | 仅本人；`name、playerUid、wechatId、hasOrangeWeapon、profession、secondaryProfession、remark` |
| `GET /api/v1/organizations/{orgId}/player-profiles/{accountId}` | 同一实际帮会的管理员／助手；同时验证目标有效绑定成员关系；俱乐部管理者不能通过此接口读取微信号 |

名字必填且最多 30 字，UID／微信号最多 64 字，备注最多 500 字；UID 为字符串，保留前导零；橙武要求真实布尔值。主副职业允许为空，非空必须有效，原报名资格规则不变。微信号不是微信授权、机器人或账号绑定。它不进入公开活动、普通成员、战报或候选 DTO，日志启用敏感字段脱敏。

迁移入口 `ruoyi-fastapi-backend/tools/migrate_player_profile_dev.py` 有完整目标库名称保护，只增加账号资料表及个人中心菜单授权，不赋予组织管理权限。保存以账号行锁串行处理首次创建，提交异常回滚资料和成员同步；DTO 在提交前构造，避免异步 ORM 过期读取。

- 两个小程序 JS／JSON 工程检查通过；通过真实 wx.request 适配和真实资料组件，登录同一后端账号、读取同一 60 席快照及颜色、交叉保存读取 UID 和橙武。没有使用假业务 API。
