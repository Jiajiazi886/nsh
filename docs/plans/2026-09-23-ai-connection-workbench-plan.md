# AI 连接工作台实施计划

1. 为多连接 VO 、密钥不回显、唯一当前项和运行时连接选择编写失败测试。
2. 扩展 `AiKeyService`：列表、新增、更新、删除、切换当前项、密钥解密与旧 Mimo 记录兼容。
3. 新增上游模型发现和工作台测试接口，覆盖 Chat Completions / Responses 协议及文字、图片消息。
4. 改造 `InternalPowerMimoService`，让真实识别请求按当前数据库配置路由，并保留无数据库的离线测试兼容。
5. 重写 `system/aiKey/index.vue` 为 RuoYi 内嵌工作台：连接列表、编辑器、模型获取、当前项切换、对话和图片测试。
6. 更新前端 API 封装，使用现有认证、传输加密和统一错误处理。
7. 增加前端纯函数测试与后端 pytest，执行语法编译、前端生产构建和完整回归。
8. 将旧 Mimo 记录安全迁移为普通连接，重启本地前后端，通过真实开发库验证列表、切换、页面和旧功能。
