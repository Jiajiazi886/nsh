# 系统管理瘦身与大模型 Token 统计设计

本设计以用户确认的实施方案为准：彻底移除通用字典、通用参数和数据库操作/登录日志；业务状态改用模块内固定枚举；账号安全配置改由环境变量提供；AI 识图额度改由单行策略表提供。

“AI连接工作台”改名为“大模型配置”，保留现有连接管理能力，并新增只对系统管理员开放的 Token 请求记录。每次真实生成请求必须先在独立数据库会话创建待处理记录；创建失败则不调用上游。供应商返回的 Usage 按协议原样记录，未返回时保留空值，不进行估算。记录不保存提示词、图片、回答或密钥。

数据库升级是不可逆迁移：先创建 `ai_usage_policy` 与 `ai_request_usage_log`，迁移额度参数和菜单数据，再删除旧字段与旧表。相同版本化迁移用于本地和服务器，避免两套结构漂移。
