## 阶段与具体任务

- [x] T00 测试隔离：先测试拒绝真实连接，再实现 runner；缓存/临时结果只在副本目录内。
- [x] T01 JWT：先覆盖坏格式、签名/算法、缺 exp/session/user、非法 ID，再实现严格解析并复用既有会话。
- [x] T02 账号状态：停用/删除/撤销会话拒绝；有效会话与多端分别退出保留兼容。
- [x] T03 本人请假/报名：匿名和伪造成员测试先失败；后端绑定 member_user_id、记录真实操作者。
- [ ] T04 事务与竞态：邀请/成员锁、请假报名互换、异常回滚、过期/关闭与跨帮会拒绝。
- [ ] T05 统一边界：/api/v1 认证、响应/错误/请求号/字符串 ID/分页、有限公开 allowlist。
- [ ] T06 业务适配与完整目录：每个已注册操作分类；复用账号/组织/职业/成员/约战/团队/排表/个人服务。
- [ ] T07 完整活动业务：模板/独立活动/六席位/职业资格/多次快照/公开抢位/截止/取消/最终快照，按已确认规则验证。
- [ ] T08 CSV/分析：固定格式、导入预览/确认、组织/活动/final/run 归属、稳定指标、盒子及失败不污染历史。
- [ ] T09 机器人身份：服务签名/重放、一次性挑战、耐久绑定/解绑、跨 bot/app 身份、停用账号隔离。
- [ ] T10 机器人业务：公开活动/职业缺口/本人/本帮/报名请假人数白名单查询、受认证文件及待处理建议。
- [ ] T11 可靠通知：偏好/职业筛选、事务 Outbox、去重、重试/死信、发送前再鉴权、真实 iLink 能力验证边界。
- [ ] T12 接入封装：fetch/wx.request 可注入 JS SDK、Python 客户端、Postman、认证/业务/错误示例。
- [ ] T13 契约及归档：OpenAPI、权限矩阵、错误码、迁移与部署说明、完整接入 ZIP、秘密与文件清单校验。
- [ ] T14 总验收：逐项需求证明、旧网页回归、真实库/微信未被测试触达、遗漏清单清零；不把 mock 当作真实微信联调。

每项循环：新增具体失败用例 → 记录根因 → 实现 → 该项测试绿色 → 相关回归 → 更新证据。
数据库并发结果必须来自隔离的目标引擎或明确保留未验证状态，不能用 SQL 字符串检查冒充真实并发测试。
